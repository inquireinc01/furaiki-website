■ 活動フォトギャラリー(活動報告ページ)の写真の入れ方

活動1回につきフォルダを1つ作り、そこに写真を入れます。
あとは「サイトを更新.bat」をダブルクリックするだけです。


【フォルダの作り方】

  YYYY-MM-DD_回数_地域        ← 活動の初日・回数・地域

  例) 2026-08-22_22_熊本
      2026-07-18_21_能登
      2026-07-12_--_広報      ← 回数が付かない活動は -- にする

  サイトでは新しい活動が上に来ます。
  フォルダを作って写真を入れるだけで、見出し(回・日付・地域)が自動で付きます。


【info.txt(任意。書くと表示が詳しくなる)】

  フォルダの中に info.txt という名前で置きます。書かなくても動きます。

    回: 第22回
    期間: 2026-08-22〜2026-08-24
    地域: 熊本
    場所: 熊本県八代市・氷川町
    災害: 令和8年熊本地震
    事業: 1
    内容: 側溝の土砂撤去、寺院の仏具搬出

  「事業」は定款 第5条の番号です。複数該当するときは 1,2 のように並べます。

    1 … 災害発生時のボランティア派遣に関する事業
    2 … 被災地の復興及び心のケア等被災者支援に関する事業
    3 … 応援フライキ普及に関する事業
    4 … ボランティアプラットフォーム構築に関する事業
    5 … その他目的を達成するために必要な事業

  「災害」は気象庁が定めた正式名称を使ってください
  (例: 令和6年能登半島地震 / 令和8年熊本地震 / 令和8年8月千葉豪雨)。


【活動後に集めておくと良い情報】

  info.txt に書く6項目は、そのまま活動記録になります。
  活動のたびに次の内容を控えておくと、あとで書くのが楽です。

    ・第○回        ・日付(初日〜最終日)
    ・場所(市町村まで)  ・対象の災害名
    ・作業内容(3つまで)  ・参加人数

  いずれも交通費の補助申請で集めている情報と同じです。


【ファイル名】

  そのままでOKです。「サイトを更新.bat」が撮影日時の名前
  (例 20260822090000.jpg)に自動で付け替えます。

  ただし LINE でやり取りした写真は撮影日時の情報が消えているため、
  自動では付きません。その場合は活動日を手で付けてください。
    例) 20260822090000_01.jpg 〜 _10.jpg

  1つの活動フォルダの中では「ファイル名の順(昇順)」に並びます。
  撮った順・見せたい順に番号を振ってください。


【載せる写真の選び方】

  「被害の記録」ではなく「復旧の過程」が伝わる写真を選びます。

  載せないほうがよいもの:
    ・個人宅の内部(持ち主の許可が確認できていないもの)
    ・表札、番地、郵便受け、車のナンバーが読めるもの
    ・散乱した私物(衣類、アルバム、食器など)
    ・仏壇の中身、位牌、遺影(仏具の搬出作業そのものは可)
    ・けが人、救護の場面
    ・飲食、入浴、打ち上げなど活動以外の場面

  笑顔の写真について:
    チームの雰囲気は大切なので載せて構いません。ただし
    ・被害の写真のすぐ隣に置かない
    ・活動前の朝礼や出発時など、文脈の分かる場面を選ぶ
    ・info.txt の「内容」に何をした日か書いておく

  表現について:
    「壊滅的」「悲惨な」といった言い方は避け、
    「壁が崩落した本堂」「土砂の堆積した側溝」のように事実で書きます。
    参加人数や日数といった数字を添えると、活動の実態が正確に伝わります。

  公開の前に:
    現地の受入団体や社会福祉協議会へ一報を入れてください。
    ボランティアセンター経由の案件は掲載のルールがある場合があります。


【サイズ・形式】

  .jpg / .png / .webp が使えます。iPhoneのHEICもそのまま入れてOKです
  (「サイトを更新.bat」が自動でJPGに変換します)。
  大きい写真は長辺1600pxに自動縮小され、スマホ用の軽量版も自動生成されます。
  各写真は横4:縦3の枠に自動トリミングされて並びます。


【写真を減らしたいとき】

  フォルダから削除して「サイトを更新.bat」を実行してください。
  軽量版(-480w/-800w)も自動で片付きます。
  フォルダごと消せば、その回の記録がまるごと消えます。
